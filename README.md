# Logiview

---

Simple logistics dashboard using React Native and Expo for learning purposes

## getting started

Clone the repo and run the following commands:

```bash
git clone https://github.com/walid-olt/logiview.git

```

Install dependencies:

```bash
pnpm install # no npm, there's a shai hulud running in the wild again

```

Run the app:

```bash
pnpm start
```

use the Expo Go app on your phone to scan the QR code and run the app.
